\section{Método de Clasificación}
Cada interesado se califica con dos valores de 1 a 5: \textbf{poder} (capacidad de cambiar el rumbo del proyecto: financiarlo, entregar datos o usar el mapa) e \textbf{interés} (cuánto le importan sus resultados). Un valor de 4 o 5 se considera alto.
